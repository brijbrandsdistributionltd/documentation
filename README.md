# Clinic OS — Platform Documentation

The complete operating handbook for **Clinic OS**, practice-management software for Australian prescribing clinics — 15 chapters and 3 appendices — now including Medicare bulk billing — covering the full patient journey: public intake, scheduling, prescribing with embedded eScripts, TGA approvals automation, pharmacy dispatch, billing and pay runs, reports, and the audit pack.

**📖 Read it live:** https://clinic-os-banksia.vercel.app/documentation

- `index.html` — the entire manual as a single self-contained file (all 32 screenshots embedded). Open it in any browser, host it anywhere, or print it as a handbook.
- Screenshots are from the demo environment; every patient shown is fictional.
